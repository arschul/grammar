Conditionals
Review

If they hadn't spent years in their laboratories, they wouldn't have had the expertise they needed.

zero · first second · third
The idea

Condition + result

Every conditional has an if-clause (the condition) and a result clause. The tenses you choose show whether the situation is real or imaginary.

Examples

If you carry out this experiment, you will see interesting results.

The world would be a different place if we didn't have them.

The golden rule

if + no will

if + no would

The if-clause always steps one tense back from the result clause.

Real conditions

Zero & first

Zero: if + present, ... present  ·  First: if + present, ... will + base verb

If you heat ice, it melts.  general truth
If the hypothesis isn't correct, the scientists form a new one.  general truth
If you have the right expertise, you will make the most of your luck.  future possibility

Zero only: you can swap if for when and nothing changes.

Unreal conditions

Second & third

Second: if + past simple, ... would + base  ·  Third: if + past perfect, ... would have + p.p.

If I were a scientist, I would like to work in a research lab.  hypothetical present
If we had more funding, we would hire two more researchers.  hypothetical present
If I had been in Fleming's position, I would not have noticed the same thing.  hypothetical past

After if, use were for every person: If he were here...

All four together

The whole system

Zero
present → present

If you heat ice, it melts.

a general truth

First
present → will + base

If you carry out this experiment, you will see results.

a future possibility

Second
past → would + base

If I were a scientist, I would work in a lab.

a hypothetical present

Third
past perfect → would have + p.p.

If I had been there, I would not have noticed it.

a hypothetical past

⚠ Watch out

Common mistakes

If it will rain tomorrow, we will cancel.

Correct: If it rains tomorrow, we will cancel.

If I would have known, I would have told you.

Correct: If I had known, I would have told you.

If she studies medicine, she will works in a hospital.

Correct: she will work in a hospital.

He wouldn't discovered penicillin.

Correct: he wouldn't have discovered penicillin.

✓ Never use will in the if-clause.

The world would be different if we didn't have them.

✓ Base verb after didn't.

If it rains tomorrow, we cancel the visit to the lab.

If it rains tomorrow, we will cancel the visit to the lab.

✓ A real future possibility needs will in the result.

If I would have known the results, I would have told you.

If I had known the results, I would have told you.
